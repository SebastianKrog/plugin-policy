# Support and contact

**Publisher:** Sebastian Krog, Denmark  
**Last updated:** 21 October 2026

This support page covers the independent plugins listed on the [project homepage](README.md).

## Get help or report a problem

Use [GitHub issues](https://github.com/SebastianKrog/plugin-policy/issues) or contact [Sebastian Krog through GitHub](https://github.com/SebastianKrog) for help, bug reports, privacy requests, security concerns or intellectual-property concerns. In public messages, describe only the general nature of the request without posting private information.

Please include the plugin name, a brief description, the expected result and a minimal example that does not contain private information. If relevant, include the plugin version and the host platform used.

**GitHub issues are public.** Do not post passwords, API keys, patient information, personal identifiers, confidential files or unredacted conversations. Do not include sensitive source material in an issue.

## Availability

These are free personal projects. Support is provided voluntarily, when available. There is no guaranteed response time, fix, ongoing maintenance or service level. Updates or continued availability cannot be promised. This does not limit statutory rights or deadlines that apply to privacy requests or other legal obligations.

For host-platform account access, billing, chat history, deletion, outages or subscription problems, contact the platform provider through its own support channels. The plugin publisher cannot administer your host account.

See the [privacy policy](PRIVACY.md) for how support correspondence is handled and the [terms](TERMS.md) for use of the plugins.
